Capítulo 1Estructura: ¿qué son las TIC?

Se usa: <html>, <head>, <title>, <body>, <h1>-<h6>, <p>, atributos

Definición

Las TIC son el conjunto de tecnologías que permiten obtener, procesar, almacenar y compartir información y comunicarnos a distancia. Incluyen computadoras, teléfonos, redes, Internet, software y servicios digitales. Hoy están presentes en la educación, la salud, el trabajo y el ocio.

Sus tres ideas clave

Información

Datos organizados que tienen significado.

Comunicación

Intercambio de mensajes entre personas o máquinas.

Tecnología

Las herramientas (hardware y software) que lo hacen posible.

Capítulo 2Texto: lenguaje de las TIC

Se usa: b, i, strong, em, sup, sub, br, hr, blockquote, q, abbr, dfn, cite, address, s, ins, del

Una red informática es un conjunto de dispositivos conectados para compartir recursos. Es muy importante proteger tus datos, y nunca compartas tus contraseñas.

La TIC más famosa es Internet, que se mide en megabits por segundo (Mbps). Un archivo de 1 GB equivale a 109 bytes, y el agua (H2O) enfría los centros de datos.

La Web es más una creación social que técnica: la diseñé para un efecto social, ayudar a la gente a trabajar junta.

Así lo expresó Tim Berners-Lee, creador de la Web (cita adaptada), en su libro Tejiendo la Red. Otra frase conocida: El futuro ya llegó, solo que no está distribuido uniformemente.

Capítulo 5Imágenes: lo que vemos de las TIC

Se usa: img (src, alt, title), figure, figcaption; clases para tamaño y alineación (Cap. 16)

El procesador es el cerebro de cada dispositivo. Los formatos de imagen más usados en la web son JPEG (fotografías), GIF y PNG (gráficos, logos y transparencias). Las imágenes deben guardarse al tamaño final, a 72 ppi, para que la página cargue rápido.

El teléfono inteligente reúne en un solo aparato cámara, Internet, GPS y miles de aplicaciones. Siempre debes poner el atributo alt en cada imagen para que los lectores de pantalla puedan describirla.

Capítulo 10CSS: cómo se da estilo a esta página

Se usa: style, selectores, cascada, herencia

Esta página usa CSS interno (en <style>); en un sitio real conviene una hoja externa con <link rel="stylesheet" href="css/estilos.css">. Una regla se compone de selector + declaración:

h2 {
  color: #0066bb;
  border-bottom: 2px solid #ee3e80;
}
  • Selectores usados: tipo (p), clase (.importante), id (#nota-id), descendiente (nav a), pseudo-clase (a:hover) y atributo (input[type="text"]).
  • Cascada: si dos reglas chocan, gana la más específica; si empatan, la última.
  • Herencia: la fuente y el color del body pasan a los demás elementos.

Capítulo 15Layout: cómo se organiza la página

Se usa: position, float, clear, overflow, min/max-width, z-index

  • Dos columnas con float: el contenido principal flota a la izquierda (68%) y la barra lateral a la derecha (25%).
  • Contenedor de flotantes: .cols usa overflow: auto para no colapsar.
  • Ancho máximo: .wrapper usa max-width: 1000px y se centra con márgenes automáticos.
  • Posición pegajosa: el menú se queda arriba, con z-index para quedar sobre el contenido.
  • Adaptable: una regla @media pasa a una sola columna en pantallas pequeñas.
